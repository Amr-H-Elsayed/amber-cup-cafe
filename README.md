## Amber Cup Cafe
A modern, responsive website for a hypothetical Amber Cup cafe. Built using the Ox Alpha AI agent. This is my very first project exploring AI-assisted web development.

## 🚀 Live Demo
You can view the website by clicking the .index file inserted in this repo.

## ✨ Features
* Modern Design: clean, cozy, and tailored to a fall-themed cafe.
* Fully Responsive: and optimized for viewing through phones, tablets, and desktops.
* AI-Generated: Created using Ox Alpha to experiment with AI prompting and development.

## ⚒️ Built with
* Ox Alpha
* HTML
* JavaScript

## 💡 What I Learned
As my first time using an AI agent, I learned how to:
1. Formulate prompts to generate web layouts.
2. Structure and review AI-generated code.
3. Deploy a project live using GitHub.
